# cebersaban44-rgb.github.io

This repository serves only the root of `cebersaban44-rgb.github.io`:

- `index.html` sends visitors on to the [Keymotion site](https://cebersaban44-rgb.github.io/keymotion/).
- `robots.txt` lets every crawler in and points to the Keymotion sitemap. Search engines read `robots.txt` only at the root of a host, so it can't live in the Keymotion repository.
- The `.txt` file named after a hex key is the [IndexNow](https://www.indexnow.org/) key. When the Keymotion site is published, its workflow tells Bing, Yandex and the other IndexNow search engines which pages changed.

Keymotion itself, a free Windows app for the AJAZZ AK980 PRO keyboard, lives at [cebersaban44-rgb/keymotion](https://github.com/cebersaban44-rgb/keymotion).
